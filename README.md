# Hotel-Booking-Chatbot-AWS
# 🏨 Hotel Booking Chatbot using Amazon Lex

## 📌 Project Overview

This project is an AI-powered Hotel Booking Chatbot developed using Amazon Lex and AWS Lambda. It allows users to book hotel rooms by selecting room type, check-in date, and stay duration. The chatbot calculates the booking cost and confirms the reservation.

---

## 🚀 Features

- Hotel Room Booking
- Room Type Selection
- Check-in Date
- Stay Duration
- Price Calculation
- Booking Confirmation
- AWS Lambda Integration

---

## 🛠 Technologies Used

- Amazon Lex V2
- AWS Lambda
- Node.js
- Cloud Computing

---

## 🏨 Available Room Types

- Classic
- Deluxe
- Suite
- Duplex
- Economy
- Executive
